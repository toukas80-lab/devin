# B2B-35 — Μενού «Τιμοκατάλογος» για κατέβασμα PDF

Branch `b2b-35` σε worktree `..\devin-b2b35` (από `origin/b2b-34`).
Χωρίς SQL, χωρίς upload, χωρίς run_sync.ps1.

## Αλλαγές

- `layout.php`: στο `<nav>`, αμέσως μετά το «Κατάλογος», προστέθηκε
  `<a href="/pricelist">Τιμοκατάλογος PDF</a>`.
- `index.php`: `'pricelist' => page_pricelist(),` στο match,
  αμέσως μετά το `'catalog'`.
- `pages.php`: νέα `page_pricelist()` στο τέλος του αρχείου —
  `require_user()`, σερβίρει το `portal/files/pricelist.pdf` ως
  attachment με όνομα `Timokatalogos_2026.pdf`,
  `Cache-Control: private, no-cache`, καθαρίζει τα output buffers
  πριν τα headers, `page_not_found()` αν λείπει το αρχείο.

## Έλεγχος

- `php -l`: δεν υπάρχει php — οπτικός έλεγχος.
- Το `portal/files/pricelist.pdf` δεν υπάρχει ακόμα στο repo —
  το `/pricelist` θα επιστρέφει 404 μέχρι να τοποθετηθεί εκεί
  (by design, δεν ζητήθηκε δημιουργία του).
- `git add` μόνο τα 4 αρχεία.
