## Αλλαγές στο page_catalog

**Νέες GET παράμετροι (whitelist μόνο — τίποτα του χρήστη δεν μπαίνει στο SQL):**

- `s`: `code` | `name` | `price`, προεπιλογή `code`
- `d`: `asc` | `desc`, προεπιλογή `asc`
- Οποιαδήποτε άλλη/κενή τιμή → προεπιλογή.

**ORDER BY ανά s** (το `$dir` είναι μόνο ASC/DESC από whitelist):

| s | ORDER BY |
|---|---|
| code | `i.code ASC\|DESC` |
| name | `i.name ASC\|DESC, i.code ASC` |
| price | `(COALESCE(p.price, i.price_w) <= 0 OR COALESCE(p.price, i.price_w) IS NULL) ASC, COALESCE(p.price, i.price_w) ASC\|DESC, i.code ASC` |

Στην τιμή τα «Ρωτήστε τιμή» (eff <= 0 / null) πάνε πάντα στο τέλος,
και στις δύο κατευθύνσεις. Η ταξινομημένη τιμή είναι η ίδια με την
εμφανιζόμενη (`COALESCE(p.price, i.price_w)` = special ή χονδρική).

**Επικεφαλίδες:** Κωδικός/Είδος/Τιμή έγιναν `<a class="sort">` προς
`/catalog` με `q,g,s,d,p=1`. Κλικ στην ενεργή στήλη αντιστρέφει το `d`,
κλικ σε άλλη ξεκινά με `asc`. Στην ταξινομημένη στήλη εμφανίζεται
▲ (asc) ή ▼ (desc) μετά το κείμενο.

**Διατήρηση s,d:** hidden inputs στη φόρμα αναζήτησης (q/g),
σελιδοποίηση, `back` των αγαπημένων (☆/★), και redirect μετά την
προσθήκη στο καλάθι — όλα τα `http_build_query` του page_catalog.

**style.css:** `a.sort{color:inherit;text-decoration:none}` και
`a.sort:hover{text-decoration:underline}`.
