# B2B-30 — Κατάλογος σε λιανική (PRICER), καλάθι λιανική −40%

Branch `b2b-30` σε worktree `..\devin-b2b30` (από `origin/b2b-29`).
Μόνο ανάγνωση (devin_ro). Χωρίς upload.

## Αλλαγές

- `export.py`, `Q_ITEMS`: `+ CAST(ISNULL(m.PRICER,0) AS float) AS price_r`
  αμέσως μετά το `price_w`.
- `migrations/014.sql`: `ALTER TABLE items ADD COLUMN price_r
  DECIMAL(12,4) NOT NULL DEFAULT 0 AFTER price_w;` — το ίδιο στο
  `CREATE TABLE items` του `schema.sql`.
- `api.php`: `'price_r'` αμέσως μετά το `'price_w'` στο map του `items`.
- `helpers.php`: `const B2B_DISC = 40.0;` — η `price_info` έγινε
  `price_info(float $pr): array`: `pr>0 → disc=40, eff=round(pr*0.60,2)`,
  αλλιώς `disc=0, eff=0`. Επιστρέφει `['w'=>$pr,'disc'=>…,'eff'=>…]`.
- `pages.php`: κάθε `price_info` τροφοδοτείται με `i.price_r` (προστέθηκε
  στα SELECT)· το `prices.price` δεν χρησιμοποιείται πουθενά (τα
  LEFT JOIN prices έμειναν). Κατάλογος/αγαπημένα: κελί = `money(price_r)`
  αν `price_r>0` αλλιώς «Ρωτήστε τιμή». Ταξινόμηση τιμής: `i.price_r`
  με `<=0` στο τέλος. Στήλη «Χονδρική» → «Λιανική» σε καλάθι και
  προβολή παραγγελίας. Έλεγχοι `eff<=0`, order_lines
  `price_w`/`disc_pct`, email, CSV αμετάβλητα.
