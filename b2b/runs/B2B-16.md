# B2B-16 — Περίληψη

Ημερομηνία: 2026-10-11. Branch: b2b-16 (από b2b-15). Μόνο κώδικας πύλης — κανένα SQL στο SoftOne.

## Αρχεία που άλλαξαν
- `portal/app/pages.php` — reorder handler/κουμπιά, ★/☆ toggle,
  νέες σελίδες `page_favorites()`, `page_quick()`.
- `portal/app/admin.php` — `admin_status()`: email στον πελάτη μόνο όταν
  η κατάσταση αλλάζει πραγματικά σε seen/done/cancelled και υπάρχει
  email («Παραγγελία W-…: <status_label>» με αριθμό/ημ/νία/σύνολο).
- `portal/app/layout.php` — μενού: «Γρήγορη παραγγελία», «Αγαπημένα».
- `portal/public/index.php` — routes `quick`, `favorites`.
- `portal/schema.sql` — νέος πίνακας `favorites` (ο sync δεν τον αγγίζει).

## Νέες σελίδες / features
- **«Ξανά στο καλάθι»** στο `/order` και `/orders` (POST+CSRF): μόνο
  για παραγγελία του ίδιου πελάτη· προσθέτει τις γραμμές που τα item_id
  υπάρχουν ακόμα στο `items`· flash με πλήθος προσθήκης και κωδικούς
  που δεν είναι πια διαθέσιμοι.
- **`/quick`**: textarea «κωδικός ποσότητα» (διαχωριστικό tab/κενό/;/,),
  ποσότητα με κόμμα ή τελεία, έως 200 γραμμές· έγκυρα → καλάθι,
  λίστα αγνοημένων (δεν βρέθηκε / άκυρη ποσότητα).
- **`/favorites`** + ☆/☆ στον κατάλογο (POST+CSRF, επιστροφή με
  q,g,m,p): λίστα αγαπημένων που είναι ακόμα ορατά (JOIN items),
  τιμή πελάτη, ποσότητα/γραμμή και κουμπί «Προσθήκη στο καλάθι» για όλα.
