## export.py

- `COMPANY = 1001`, νέα σταθερά `STOCK_COMPANY = 3000`. Κάθε `COMPANY=…`
  στα queries (Q_ITEMS, Q_GROUPS, Q_CUSTOMERS, Q_BALANCES, Q_PRICES,
  Q_LEDGER, Q_OPENING, Q_INVOICES, Q_BALSHEET) → `{COMPANY}` (f-strings).
- **Προ-έλεγχος (2):** CODE είδους (SODTYPE=51) σε >1 MTRL στην 3000 →
  **0** — το stock-by-CODE join είναι ασφαλές.
- `Q_ITEMS.stock`: `TOP 1 d.QTY1` από `MTRL s (COMPANY=STOCK_COMPANY,
  SODTYPE=51, CODE=m.CODE) JOIN MTRDATA d ON MTRL+COMPANY`, `ORDER BY
  FISCPRD DESC`.
- `Q_INVOICES`: `TFPRMS IN (102,103,131,151,152,181)`, πρόσημο −1 για
  `(151,152,181)`, `LEFT JOIN MTRDOC md ON md.FINDOC=f.FINDOC`,
  `einv_url = ISNULL(md.SOSIGNQR,'')`. Στην Python κρατιέται μόνο αν
  αρχίζει με `https://einvoice.impact.gr/p/` ή
  `https://einvoice.s1ecos.gr/p/` και ≤255 χαρακτήρες. Αν έβγαινε διπλό
  `findoc_id` → `sys.exit` — **δεν βγήκε** (το join είναι 1:1).
- `Q_PRICES`: ίδιο, μόνο εταιρεία.
- `findstr /n "3000" b2b\sync\export.py`:
  ```
  14:STOCK_COMPANY = 3000
  ```
