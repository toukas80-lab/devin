# B2B-34 — Φίλτρο «Κεφάλαιο» στον κατάλογο

Branch `b2b-34` σε worktree `..\devin-b2b34` (από `origin/b2b-34`,
με το έτοιμο `b2b/sync/catalog_chapters.tsv` — 856 γραμμές
`CODE<TAB>ΚΕΦΑΛΑΙΟ`). Μόνο ανάγνωση (devin_ro). Χωρίς upload.

## Αλλαγές

- `export.py`: `CHAPTERS_FILE` + `CATALOG_CHAPTERS` (dict code→κεφάλαιο,
  split στο πρώτο TAB, strip, χωρίς κενές γραμμές· κενό dict αν λείπει).
  Μετά το φίλτρο `CATALOG_CODES`: `it["chapter"] =
  CATALOG_CHAPTERS.get(code, "")`.
- `015.sql`/`schema.sql`: `items.chapter VARCHAR(100) NOT NULL
  DEFAULT ''` μετά το `group_id`.
- `api.php`: `'chapter'` μετά το `'group_id'` στο items map + guard
  `null → ''` δίπλα στο υπάρχον `opening`.
- `pages.php` (μόνο `page_catalog`): GET `c`, `AND i.chapter = ?`,
  `SELECT DISTINCT chapter … ORDER BY chapter`, `<select name="c">`
  ΠΡΙΝ το select ομάδων με «Όλα τα κεφάλαια» πρώτο, και `'c' => $c`
  σε κάθε `http_build_query` με `'g'` (redirect, sort links, φόρμα
  καλαθιού, back αγαπημένων, σελιδοποίηση).
