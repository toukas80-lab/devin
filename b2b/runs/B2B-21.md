# B2B-21 — Ημερομηνίες σε μορφή DD/MM/YYYY

## Σκοπός

Όλες οι ημερομηνίες που εμφανίζονται στον πελάτη και στον διαχειριστή
(και στα κείμενα email) αποδίδονται ως DD/MM/YYYY αντί για YYYY-MM-DD.
Οι τιμές που αποθηκεύονται, συγκρίνονται ή μπαίνουν σε
`<input type="date">` δεν άλλαξαν (μένουν ISO YYYY-MM-DD).

## Αρχεία που άλλαξαν

- `b2b/portal/app/helpers.php`
- `b2b/portal/app/pages.php`
- `b2b/portal/app/admin.php`
- `b2b/runs/B2B-21.md` (αυτό)

## helpers.php

Νέα συνάρτηση `dmy($d): string` (τέλος αρχείου):

- κενό / null -> `''`
- `YYYY-MM-DD` -> `DD/MM/YYYY`
- `YYYY-MM-DD HH:MM(:SS)` -> `DD/MM/YYYY HH:MM`
- οτιδήποτε άλλο επιστρέφεται ως έχει
- υλοποίηση μόνο με `preg_match` / `substr`, χωρίς timezone

## Σημεία που άλλαξαν (function : σημείο)

### pages.php

- `page_home` (~γραμμή 216): `e($o['created_at'])` -> `e(dmy($o['created_at']))` (τελευταίες παραγγελίες)
- `page_order` (~γραμμή 572): `e($o['created_at'])` -> `e(dmy(...))` (επικεφαλίδα παραγγελίας)
- `page_orders` (~γραμμή 618): `e($o['created_at'])` -> `e(dmy(...))` (λίστα παραγγελιών)
- `page_ledger` (~γραμμή 913): `e($from)` -> `e(dmy($from))` (γραμμή «Υπόλοιπο μεταφοράς»)
- `page_ledger` (~γραμμή 923): `e($r['date'])` -> `e(dmy($r['date']))` (κινήσεις καρτέλας)
- `page_invoices` (~γραμμή 987): `e($r['date'])` -> `e(dmy($r['date']))` (παραστατικά)

### admin.php

- `page_admin` (~γραμμή 102): `e($s['synced_at'])` -> `e(dmy($s['synced_at']))` (τελευταίος συγχρονισμός ανά dataset)
- `page_admin` (~γραμμή 116): `e($o['created_at'])` -> `e(dmy(...))` (λίστα παραγγελιών διαχείρισης)
- `admin_status` (~γραμμή 174): email πελάτη, «Ημερομηνία:» . `dmy($o['created_at'])`
- `admin_users` (~γραμμή 259): `e($x['last_login'] ?? '—')` -> `e(dmy(...))` (τελευταία είσοδος)

## Τι ΔΕΝ άλλαξε

- SQL, ORDER BY, συγκρίσεις `$r['date'] < $from` / `> $to` (γίνονται σε ISO).
- `date_param()` και τα `value` των `<input type="date">` (παραμένουν Y-m-d).
- Emails παραγγελίας στο `page_order`: δεν περιέχουν ημερομηνία.
- `admin_order_csv`: εξάγει μόνο code/qty/price, χωρίς ημερομηνία.
- `last_login = NOW()` UPDATE (δεν είναι εμφάνιση).
