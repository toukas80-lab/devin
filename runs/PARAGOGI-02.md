## 4. Σύγκριση CODE 1001 vs 3000

- Κοινοί κωδικοί και στις δύο εταιρείες: **353**
- Μόνο στην 1001 (0): —
- Μόνο στην 3000 (0): —
- Διπλότυποι CODE εντός ίδιας εταιρείας: κανένας

## 5. Παρατηρήσεις

- **`CODE1`/`CODE2` — αντίστροφα από τις ετικέτες του task:** στα δεδομένα το `CODE1` κρατάει **13-ψήφιο barcode** (π.χ. `5200000011906`) και το `CODE2` τον **αλφαριθμητικό κωδικό καταλόγου** (π.χ. `SB PE81-22.2x22.2x155`).
- `ISACTIVE`: 1 = ενεργό, 0 = ανενεργό.
- Η JOIN σε MTRGROUP/MTRCATEGORY έγινε με `COMPANY` + `SODTYPE` + id για να μη διπλασιαστούν γραμμές.

## 6. SQL που εκτελέστηκε

```sql
-- Q1
SELECT TABLE_NAME, COLUMN_NAME FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME LIKE '%MANF%' OR COLUMN_NAME LIKE '%MANFCTR%'
ORDER BY TABLE_NAME, ORDINAL_POSITION
```

```sql
-- Q2
SELECT COMPANY, MTRMANFCTR, CODE, NAME, ISACTIVE FROM dbo.MTRMANFCTR
WHERE NAME LIKE '%CRAZY%' ORDER BY COMPANY
```

```sql
-- Q3
SELECT COMPANY, ISACTIVE, COUNT(*) AS N FROM dbo.MTRL
WHERE COMPANY IN (1001,3000) AND MTRMANFCTR=1018
GROUP BY COMPANY, ISACTIVE ORDER BY COMPANY, ISACTIVE
```

```sql
-- Q4
SELECT m.MTRL, m.CODE, m.CODE1, m.CODE2, m.NAME,
       ISNULL(g.NAME,'-') AS MTRGROUP_NAME, ISNULL(c.NAME,'-') AS MTRCAT_NAME,
       CAST(m.PRICER AS decimal(18,2)) AS PRICER, m.ISACTIVE
FROM dbo.MTRL m
LEFT JOIN dbo.MTRGROUP g ON g.MTRGROUP=m.MTRGROUP AND g.COMPANY=m.COMPANY AND g.SODTYPE=m.SODTYPE
LEFT JOIN dbo.MTRCATEGORY c ON c.MTRCATEGORY=m.MTRCATEGORY AND c.COMPANY=m.COMPANY AND c.SODTYPE=m.SODTYPE
WHERE m.COMPANY={company} AND m.MTRMANFCTR=1018
ORDER BY m.CODE
```

```sql
-- Q5
SELECT CODE FROM dbo.MTRL WHERE COMPANY=1001 AND MTRMANFCTR=1018
EXCEPT
SELECT CODE FROM dbo.MTRL WHERE COMPANY=3000 AND MTRMANFCTR=1018
ORDER BY 1
```

```sql
-- Q6
SELECT CODE FROM dbo.MTRL WHERE COMPANY=3000 AND MTRMANFCTR=1018
EXCEPT
SELECT CODE FROM dbo.MTRL WHERE COMPANY=1001 AND MTRMANFCTR=1018
ORDER BY 1
```

```sql
-- Q7
SELECT COUNT(*) FROM (
  SELECT DISTINCT CODE FROM dbo.MTRL WHERE COMPANY=1001 AND MTRMANFCTR=1018
  INTERSECT
  SELECT DISTINCT CODE FROM dbo.MTRL WHERE COMPANY=3000 AND MTRMANFCTR=1018) x
```

```sql
-- Q8
SELECT COMPANY, CODE, COUNT(*) AS N FROM dbo.MTRL
WHERE COMPANY IN (1001,3000) AND MTRMANFCTR=1018
GROUP BY COMPANY, CODE HAVING COUNT(*)>1 ORDER BY COMPANY, CODE
```
